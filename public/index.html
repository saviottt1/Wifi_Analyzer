Local Wi-Fi Scanner Required

Wi-Fi scanning requires the local scanner agent to be running on your computer.
The Render server cannot access your computer's Wi-Fi adapter.

1
Clone the repository git clone https://github.com/saviottt1/Wifi_Analyzer.git
2
Run One-Click Launcher Double-click start-scanner.bat (Windows) or ./start-scanner.sh (Linux/Mac)
3
Return to this page The scanner will connect automatically.

Tip: Place a shortcut to start-scanner.bat in your Windows Startup folder (shell:startup) to run automatically on boot!
